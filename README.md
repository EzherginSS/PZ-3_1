# Анализ качества обслуживания полиции Сиэтла

## Описание проекта
Проект представляет собой комплексный анализ удовлетворенности клиентов службы 911 полиции Сиэтла за период 2006-2015 годов. На основе данных опроса разработаны интерактивные дашборды в двух BI-инструментах: Yandex DataLens и Tableau.

## Цели работы
1. Реализовать data-driven решение для мониторинга ключевых метрик качества обслуживания
2. Создать интуитивно понятные дашборды для бизнес-пользователей
3. Провести сравнительный анализ возможностей Yandex DataLens и Tableau
4. Применить принципы эффективного дизайна визуализаций

## Ключевые метрики
- **NPS (Net Promoter Score)**: -15 (преобладают критики)
- **CSAT (Customer Satisfaction)**: 6.8/10 (средняя удовлетворенность)
- **CES (Customer Effort Score)**: 2.1/5 (процесс вызова сложнее оптимального)

## Основные выводы
1. Созданы два полнофункциональных дашборда с интерактивными элементами
2. Tableau предоставляет более широкие возможности для сложной аналитики (LOD выражения, параметры, прогнозирование)
3. Yandex DataLens проще в освоении и эффективен для быстрых проектов в российской экосистеме
4. Оба инструмента соответствуют основным принципам эффективного дизайна визуализаций
5. Наибольшая проблема сервиса - сложность процесса соединения с оператором 911 (23% случаев)

## Рекомендации
- Для международных проектов со сложной аналитикой рекомендован Tableau
- Для быстрых проектов в РФ с ограниченным бюджетом - Yandex DataLens
- Приоритетное направление улучшений - оптимизация процесса соединения с операторами 911
